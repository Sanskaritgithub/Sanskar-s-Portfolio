## 📌 Overview

This is my personal portfolio website built using **React & Vite**, showcasing my skills, projects, experience, and ways to connect with me professionally. The website is fully responsive and optimized for performance, making it suitable for employers, recruiters, and collaborators.

## 🧑‍💻 Getting Started (Local Setup)

### Clone the repository

```bash
git clone https://github.com/Sanskaritgithub/Sanskar-s-Portfolio.git

Navigate to folder
cd your-repo-name

Install dependencies
npm install


Run development server
npm run dev


After running, open:
👉 http://localhost:5174/

Create production build
npm run build

Preview build (optional)
npm run preview
```
🚀 Deployment

This portfolio is deployed on Vercel.

Deploy manually:

npm run build


Upload dist/ folder or connect GitHub repo to Vercel for auto-deploy.
